- Niveaux et upgrades : XP **commune** dans `AYSGameState` (`TeamLevel`, `TeamExperience`, `ExperienceToNextLevel`, répliqués). NME : `Level` (0), PV = `BaseHealth` 100 + `HealthPerLevel` 10 × Level, dégâts de contact = `BaseContactDamage` 5 + `ContactDamagePerLevel` 3 × Level, XP à la mort = `BaseExperience` 1 + `ExperiencePerLevel` 1 × Level (catégorie `Foe|Level` ; `MaxHealth`/`ContactDamage` calculés au BeginPlay ; les NME ne montent pas encore de niveau ; `GetFoeLevel()` car `AActor::GetLevel` existe). `AYSGameMode::AddTeamExperience` : seuil = `LevelUpBaseExperience` 5 + `LevelUpExperiencePerLevel` 5 × niveau (catégorie `Level`) ; à chaque niveau : `SetPause` pour tous, chaque joueur vivant reçoit `UpgradeChoiceCount` 3 propositions (`AYSPlayerState::UpgradeOffers` = `FYSUpgradeOffer` {index dans `UpgradePool` du perso, rareté tirée à la proposition} ; `PickUpgradeOffers`, SANS remise, pour chaque proposition : 1) rareté tirée selon `GetRarityChance` du perso (`BronzeChance` 50 / `SilverChance` 40 / `GoldChance` 10, catégorie `3C|Upgrades` ; la `Luck` retire ses points au Bronze (min 0) et les donne au Gold ; une rareté sans upgrade possible sort du tirage) 2) upgrade parmi les variantes `CanBeOffered` qui existent dans cette rareté (`bCanBeBronze/Silver/Gold` de l asset), pondérée par `OfferWeight` (par variante) ; que des propositions différentes, moins de 3 s il n en reste pas assez ; aucune = joueur pas attendu) ; reprise quand tous ont choisi (`ChosenUpgradeOffer`), niveaux multiples enchaînés. Progression = `AYSPlayerCharacter::UpgradeProgress` (liste {PoolIndex, Variant, `Stacks`, `TotalValue`}, répliquée, `GetUpgradeProgress(Pool, Variant)`). `UYSStatUpgrade` : stat = valeur de base × (1 + somme des bonus) ; `MaxStacks` 10 (ensuite plus proposée), rareté Bronze / Silver / Gold (valeurs par asset, couleurs, raretés possibles, catégorie `Upgrade|Rarity`), `StatLabel` ; carte = nom et rareté (couleur de rareté), « Bonus N / 10 », description, **valeur concrète** : nom puis actuelle rayée et nouvelle en gras sur une ligne (« Dégât » : 40 -> 76 ; sous-classe = `GetBaseStatValue` + `ApplyMultiplier`). `DA_Upgrade_MoveSpeedBonus` (`UYSMoveSpeedBonusUpgrade`, 0.025 / 0.05 / 0.1) : `MoveSpeedMultiplier` du perso (répliqué, OnRep -> MaxWalkSpeed = MoveSpeed × multiplicateur, pour la prédiction). `DA_Upgrade_HpsBonus` (`UYSHealthBonusUpgrade`, 0.05 / 0.1 / 0.2) : `MaxHealthMultiplier` (répliqué ; `GetMaxHealth()` = MaxHealth de base × multiplicateur, les PV max gagnés s ajoutent aux PV actuels).
